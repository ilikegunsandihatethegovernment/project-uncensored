# Project Uncensored

Project Uncensored is an open-source AI model developed from scratch by solo developer **timelord919**. It aims to explore a different approach to AI: deep reasoning, spatial reasoning, and focused analysis that prioritizes checking verified sources, with little to no algorithmic influence.

The goal is to create an AI that is less constrained by algorithmic steering while remaining transparent about how it works and what it can do.

## Project goals

- **Built from scratch:** An original model, rather than another model presented under a new name.
- **Deep reasoning:** Work toward stronger multi-step analysis.
- **Spatial reasoning:** Explore reasoning about spatial relationships and structure.
- **Source-aware analysis:** Prioritize checking verified sources when evaluating claims.
- **Minimal algorithmic influence:** Aim to reduce algorithmic steering in the model’s responses.

These are project aims, not guarantees of current capabilities. Model behavior and features may change as development progresses.
